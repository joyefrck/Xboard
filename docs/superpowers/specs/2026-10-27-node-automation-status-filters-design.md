# 自动化配置状态配色与多选筛选

用户已确认按推荐方案实现，并追加授权验证后直接发布生产。

## 状态与颜色

保留后端状态及其原有业务含义。前端统一生成展示状态，供列表标签、IP 管理弹窗标签和快速筛选复用，避免同一域名的颜色与筛选分类不一致。

| 筛选分类 | 条件 | 标签文字 | 色系 | 浅色底 / 深色字 | 选中底 / 字 |
| --- | --- | --- | --- | --- | --- |
| 正常 | healthy 且备用数量 > 0 | 正常 | 翡翠绿 | #ECFDF5 / #047857 | #047857 / #FFFFFF |
| 正常 · 无备用 | healthy 且备用数量 = 0 | 正常 · 无备用 | 金黄 | #FEFCE8 / #854D0E | #854D0E / #FFFFFF |
| 异常 | suspect、no_backup、probe_error、config_error、dns_conflict | 保留具体异常名称 | 琥珀橙 | #FFF7ED / #C2410C | #C2410C / #FFFFFF |
| 已暂停 | paused | 已暂停 | 石板蓝 | #EFF6FF / #475569 | #475569 / #FFFFFF |
| 未配置 | unconfigured | 未配置 | 中性灰 | #F1F5F9 / #64748B | #64748B / #FFFFFF |
| 处理中 | switching、propagating、dns_unknown | 保留具体进度名称 | 靛蓝 | #EEF2FF / #4338CA | #4338CA / #FFFFFF |

备用数量沿用当前界面口径：已启用且 IP 不等于当前 IP 的备用条数。绿色代表后端报告正常且存在已启用备用，不额外宣称每个备用均已通过测试。未知状态保留原文字，以中性灰显示，并纳入“其他”筛选，防止未来新增状态被漏掉；没有未知状态时不显示“其他”。

标签采用轻背景、细边框和深色文字，克制使用色彩；深色主题提供对应的低亮度底色及高亮文字，避免亮底刺眼。所有标签保留文字提示，不仅依靠颜色区分。

## 筛选交互

在“节点与备用池”标题及搜索栏下方、表头上方新增可换行的快速状态按钮组。顺序为“全部、正常、正常 · 无备用、异常、已暂停、未配置、处理中”，每项显示域名数量，0 数量项也保留，避免轮询时按钮移动。

默认没有指定状态，“全部”选中。点击状态按钮独立切换选中状态，支持多选；所选状态之间按 OR 取并集，与搜索条件按 AND 组合。点击“全部”清空状态选择；取消最后一个状态后恢复全部。全部按钮使用页面主色，其余按钮使用对应状态色：未选中浅底深字、选中深底白字。保持同一按钮位置、尺寸与文字，避免切换跳动。

状态数量按搜索匹配后的域名统计，不受当前状态选择影响，方便继续添加状态；“全部”显示搜索匹配总数。页脚继续显示最终匹配数与总域名数。空结果提供“清除筛选”按钮，同时清空搜索和状态选择。

使用原生 button 和 aria-pressed 表达多选状态，支持 Tab、Enter、Space，并保留可见焦点。数量加载前显示占位符而非误导性的 0。筛选仅在当前页面内保存，切换页签和自动刷新时保留，重新进入页面时恢复默认。

## 实现与验证

修改现有 node-automation.js 与 node-automation.css，不引入依赖，不修改接口、排序或自动切换行为。状态分类、备用数量和搜索筛选采用共享函数，避免在列表与弹窗中重复判断。

复用内存 API 预览补齐正常有备用、正常无备用、已暂停、未配置、异常及处理中数据，检查多选并集、取消选择、全部重置、搜索组合、空结果、轮询更新，以及桌面/手机与浅色/深色显示。运行现有自动化模块和后台资源缓存检查，并通过版本脚本更新静态资源引用。
