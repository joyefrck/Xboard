# 可用用户统计与流量包到期权限同步

用户已批准修复生产排查发现的两项问题。保留 `activeUsers` 接口字段，将含义与展示文案统一为“当前可用用户”：未封禁、非待人工开通，且有效套餐尚有余额，或至少一个 active 流量包尚有余额。使用 EXISTS 按用户去重，不调用会写入权限的 `isAvailable()` 做计数。

新增每分钟权限同步命令。仅筛选套餐已不可用、仍有有效包余额、权限属性与 FIFO 首个有效流量包不一致的用户。源产品选择与现有 `syncAccessProfile()` 一致。只同步权限组、限速、设备数；不改变期限、套餐额度、已用流量、流量包余额或账户余额。逐用户事务先锁用户再锁包，复查封禁、待开通、套餐续费和包耗尽，避免与支付/流量处理竞争。

命令支持 dry-run 和限定用户 ID，定时任务采用单实例、禁止重叠。测试覆盖过期/无套餐/永久套餐/耗尽/封禁/待开通/多包去重，以及续费竞争、FIFO 切换、重复执行和数据不变。生产先备份源码及候选用户属性，再部署最小补丁并重载 Web/Horizon，验证人数、候选清零、实际全部队列、自然业务消费、失败任务和公开服务。保留现有未提交 Horizon 修复，不创建分支，不推送 GitHub。
