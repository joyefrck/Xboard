# 搬瓦工后台自动同步开关

用户在确认页面“自动刷新”不控制供应商调用后，要求增加“自动同步”开关。本轮是已授权生产功能的继续完善。

- 在服务器列表工具栏增加“自动同步”，与“自动刷新”分开。默认保持开启，设置保存在服务端，全部管理员与后台进程共用。
- 关闭后，五分钟调度不再提交自动任务；排队中的自动任务执行时跳过，并清理自身排队标记。导入后的隐式同步也遵循该设置。
- 已发出的 HTTP 请求允许完成；同一自动任务在调用第二个接口前再次检查开关。手动单台刷新、同步全部和明确的密码重置仍可使用。
- 重新开启仅恢复原有五分钟调度，不额外立即请求全量供应商数据。页面说明清楚显示启停状态及手动操作边界。
- 设置从现有设置表直接读取，避免常驻 worker 内配置缓存；保存使用现有设置写入与缓存失效机制，并以独立分布式锁避免并发首次保存。
- 自动任务携带来源标记，旧任务缺少标记时保守视为自动任务；手动新任务明确标为手动。队列仍只包含 ID、token 和布尔来源，无凭据。
- 维持独立 bandwagon 队列、五分钟调度、现有冷却、实例互斥及失败保留。页面保存失败时保持原开关状态并显示错误。

验收覆盖默认值、服务端持久化、同一 worker 读新值、调度关闭/恢复、关闭后排队任务、接口之间关闭、手动操作、导入、旧任务兼容、无缓存响应、非法输入及页面保存失败/重新载入。发布时备份十二个运行文件，平滑重载 Web 并让 Horizon 退出旧 worker，完成全量队列和公网复查，不制造业务数据或测试通知。
