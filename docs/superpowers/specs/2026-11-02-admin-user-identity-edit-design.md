# 用户编辑身份字段保护

用户已指定交互：邮箱、邀请人邮箱、密码默认锁定，各自右侧点击编辑图标才启用；密码提供显示/隐藏按钮。保持现有抽屉和其他业务字段布局。

邮箱显示当前用户邮箱。邀请人只显示数据库中实际的邀请人邮箱，没有邀请人则为空，不使用浏览器提供的默认值。密码每次打开均为空，不读取或回显现有密码；眼睛仅查看本次新输入的密码。

每个字段可独立启用、取消编辑。取消时恢复原始值并清除该字段的 dirty 状态；关闭、重新打开、切换用户均清空编辑状态和密码可见状态。默认禁用输入并阻止锁定字段的 change 事件，同时在提交前恢复锁定字段，再在构造请求时排除所有未主动启用的身份字段。密码为空时不提交。

后端仅在请求明确包含邀请人邮箱时修改邀请关系；省略字段必须保留原关系，明确清空才解除。邀请人邮箱纳入请求验证，不允许不存在的邮箱静默解除关系。

验证使用隔离的 Node 组件运行测试、内存 SQLite 控制器测试，以及本地浏览器界面检查。所有示例使用虚构用户，不写生产账号。用户已在完成本地验证后授权发布生产；发布时执行 Xboard 完整发布检查，保留现有生产热修复和业务数据，不重置任何用户凭据。
