# 官网定价入口下移设计

## 目标

将官网顶部的“定价方案”入口移至页面最底部，与“服务条款”“隐私政策”保持同一行。首页与定价页使用一致导航，桌面和移动端行为一致。

## 现状

`public/landing/index.html` 与 `public/pricing.html` 都存在两处定价入口：顶部 `.nav-link` 和底部 `.footer-pricing-link`。底部入口默认被 `display: none` 隐藏，仅在移动端媒体查询中显示。

## 方案比较

- 只用 CSS 隐藏顶部入口：保留不可见的重复导航，语义和自动测试容易混淆。
- 删除顶部入口并永久显示底部入口，采用：DOM 中每页只保留一个定价链接，结构直接、无运行时依赖。
- 页面加载后用 JavaScript 移动入口：会产生布局变化，且没有必要。

## 页面结构

首页和定价页顶部均只保留品牌、登录和注册。页脚链接顺序固定为：

1. 定价方案
2. 服务条款
3. 隐私政策

三个链接沿用现有 `.footer-links` Flex 布局，因此保持同一行；不改变链接地址、文案、颜色、间距和移动端样式。

## 变更范围

- 修改 `public/landing/index.html`。
- 修改 `public/pricing.html`。
- 新增聚焦测试，验证两个页面顶部不再包含定价链接、页脚包含且按固定顺序展示三个链接、隐藏规则已移除。
- 不修改首页图片优化、定价数据加载、登录注册按钮、政策页面和 Laravel 路由。

## 本地验收

- 聚焦测试与现有官网回归测试全部通过。
- 首页和定价页 HTTP `200`。
- 浏览器桌面视口中顶部不显示“定价方案”，页脚同一行显示三个链接。
- 点击底部“定价方案”可从首页进入定价页；服务条款和隐私政策链接保持可用。
- 控制台无新增错误或警告。

## 回滚

恢复两个顶部链接，并重新启用桌面端 `.footer-pricing-link { display: none; }` 即可；不涉及容器、数据库或持久化数据。
