# Xboard Dashboard 2.0 极光棱镜视觉优化设计

## 目标与边界

本轮只升级 `/dashboard` 的视觉表现和图标系统，不改变已确认的桌面布局、区域顺序、信息密度、数据接口、路由与交互功能。全站 V2 左侧导航继续保持当前宽度和五个入口；桌面端仍为订阅与 Telegram、客户端下载、公告与快捷入口及邀请返利三行结构。

视觉目标是现代科技感的轻量毛玻璃界面：右侧工作区使用淡雾灰底色，白色半透明卡片形成清晰层级，青蓝到紫罗兰作为品牌强调色。界面需保持可读、克制，不能依赖大面积高饱和渐变制造效果。

## 视觉语言

### 色彩

- 工作区底色：淡雾灰 `#edf1f6`，允许叠加不超过 `0.06` 透明度的局部蓝紫光晕。
- 主卡片：半透明冷白玻璃，建议由 `rgba(255,255,255,0.76)` 过渡到 `rgba(250,252,255,0.50)`。
- 卡片描边：白色高光边，建议 `rgba(255,255,255,0.72)`；内部控件使用更弱的冷灰描边。
- 品牌主色：青色 `#00abbc`、科技蓝 `#4c66e7`、紫罗兰 `#8759ec`，仅用于主操作、进度和图标色块。
- 成功状态继续使用绿色；问题申诉继续使用低饱和红色；邀请卡允许少量暖金光晕。
- 正文使用深蓝灰而非纯黑，辅助文本采用冷灰蓝，保证浅色背景下的对比度。

### 毛玻璃层级

- 页面底层不使用玻璃，采用稳定的淡雾灰实体背景。
- 一级功能卡使用 `backdrop-filter: blur(22px–26px) saturate(135%–145%)`、白色高光描边和柔和冷色阴影。
- 卡片内部指标、下载项、公告项和邀请信息行使用更轻的半透明白层，不重复使用强阴影。
- 只保留极弱的局部光晕；不添加大面积彩色背景，不改变现有空间布局。

### 图标系统

- 不再使用 `⌂`、`◇`、`↗`、`?`、`●`、`▦`、`◆` 等 Unicode 字符充当图标。
- 所有新图标使用本地内联 SVG，不增加远程字体、图标库或网络依赖。
- 菜单图标采用统一的青蓝到紫罗兰实心圆角色块，内部使用白色实心符号；未选中菜单可降低饱和度，但形状和尺寸不变。
- 下载平台采用统一尺寸的实心圆角色块：Android 绿色、Windows 蓝色、macOS 石墨色、iOS/Karing 蓝紫渐变；内部符号统一为白色实心图形。
- Telegram 与快捷入口沿用品牌青蓝—紫罗兰色块，保持相同圆角、光泽和阴影。
- 图标色块在桌面端约 `38–42px`，菜单端约 `30–32px`；移动端等比缩小，点击热区不小于 `36px`。

## 组件细节

- 左侧导航保持现有位置和宽度，选中项使用半透明白玻璃底与轻微描边；侧栏不放置品牌水印，避免与菜单和申诉入口竞争。
- 订阅卡仍是最主要区域，进度条改为青蓝—蓝紫渐变；主按钮使用同系渐变，次按钮保持半透明白玻璃。
- Telegram 卡只增加局部紫色冷光和实心 Telegram 图标，不改变其文本与按钮状态逻辑。
- 下载区四个平台按钮保持当前四列结构；每个平台图标采用独立平台色，但按钮背景、圆角和文字层级完全统一。
- 公告、快捷入口和邀请卡保持当前三列；快捷入口图标改为实心色块，邀请卡保留极淡暖金光晕作为唯一辅助暖色。
- 顶部问候、系统顶部工具和右侧系统账户区域布局不变，只统一文字颜色与玻璃高光关系。

## 交互与无障碍

- 悬停只使用 `120–180ms` 的轻微上移、描边增强和阴影变化，不改变元素尺寸。
- 实心图标为装饰时设置 `aria-hidden="true"`；按钮继续保留明确的文本和无障碍名称。
- 焦点样式使用品牌青蓝外轮廓，不能只依赖阴影或颜色变化。
- 禁用下载项降低整体透明度，但平台色块仍需保持可识别；不得显示可点击指针。
- 遵守 `prefers-reduced-motion`，关闭非必要位移和渐变动画。

## 主题与响应式

- Dashboard 2.0 固定使用浅色极光玻璃主题，不提供深色模式入口。
- `1024–1279px`、`768px` 以下和移动端继续使用现有布局断点，不新增、删除或重新排序任何区域。
- 视觉样式不得增加现有页面高度；在当前真实浏览器尺寸下继续保持 Dashboard 根节点无纵向溢出。

## 实现与验收

- 在 `elephant-route-dashboard-v2.js` 中增加可复用的内联 SVG 图标映射，替换侧栏、下载、Telegram 和快捷入口的字符图标。
- 在 `elephant-route-dashboard-v2.css` 中重构颜色变量、页面底色、玻璃材质、平台色块与交互状态；主题与 `public` 资源逐字同步并更新缓存版本。
- 回归测试新增 Unicode 图标清理、内联 SVG、平台色块类名、雾灰底色、毛玻璃与浅色主题锁定断言。
- 使用当前登录 Chrome 检查浅色主题、路由切换、禁用下载项和键盘焦点；运行既有 Dashboard、下载、Telegram、申诉与流量包回归测试。

## 后续确认微调：顶栏与底部弱图案

### 顶栏

- 删除问候语上方的 `DASHBOARD 2.0` 辅助标签，只保留问候语和账户邮箱。
- 菜单折叠按钮、问候语、系统工具和账户区域位置不变，不增加新的标题或占位高度。

### 官方公告背景

- 在卡片右下角加入“广播波纹”实心 SVG 弱图案，用不完整同心波纹和中心信号点表达公告传播。
- 图案使用青蓝色系，桌面尺寸约 `104–116px`，透明度控制在 `0.035–0.05`。
- 图案不能穿透到公告标题的主要阅读区域；三条公告内容始终位于图案之上。

### 快捷入口背景

- 在卡片右下角加入与公告不同的“模块矩阵”实心 SVG 弱图案，用四个圆角模块和短连接线表现科技快捷入口。
- 图案使用蓝紫色系，桌面尺寸约 `104–116px`，透明度控制在 `0.03–0.045`。
- 四个快捷按钮始终位于图案之上，图案不改变按钮边框、点击区域或卡片高度。

### 结构和无障碍

- 两个图案复用统一水印容器和独立修饰类，使用本地内联 SVG，不增加网络资源。
- 水印容器设置 `aria-hidden="true"` 和 `pointer-events: none`；标题、公告列表和快捷按钮的层级高于水印。
- 保留现有三列布局、毛玻璃材质、安全边距和首屏高度。

### 验收

- 回归测试覆盖顶部标签移除、两个不同 SVG 图案、装饰性无障碍属性、主题与 public 资源同步以及缓存版本更新。
- 使用当前登录 Chrome 检查图案辨识度、文字可读性、无纵向溢出和控制台错误。
