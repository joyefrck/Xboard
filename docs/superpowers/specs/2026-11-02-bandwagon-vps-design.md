# 搬瓦工 VPS 管理

用户已选择功能 1、2、3、4，以及 11 中的重置 root 密码。

- 节点管理增加「搬瓦工VPS管理」。多行框解析官方导出 CSV（VEID、VM_TYPE、HOSTNAME、PRIMARY_IP、IS_TERMINATED、IS_2FA_ENABLED、API_KEY），预览不回传密钥；默认跳过已终止条目，按 VEID 更新。单次最多 500 行、256 KiB。
- 列表展示备注、VEID、主机名、最新 IP、机房、系统、套餐、资源配额、本周期流量与重置时间，以及接口可用的运行、负载、内存、磁盘和限速信息。支持搜索、状态筛选、单台刷新、全部同步、修改备注、移除记录。
- 密钥经 APP_KEY 加密，供应商请求固定 HTTPS POST，禁止重定向、不自动重试。只接入 getServiceInfo、getLiveServiceInfo、resetRootPassword。
- 每五分钟调度独立 bandwagon 队列，单实例去重及互斥，失败保留上次数据和时间，实时信息单独标明过期/失败。供应商返回字段白名单存储，排除控制台截图等内容。
- 自动化当前 IP 精确匹配最新同步的 IPv4/IPv6 地址；多个实例匹配时显示冲突，不猜测；未同步/密钥变更不采用导出 IP 作有效匹配。同 VPS 多 IP 共用 VPS 流量。80%/95% 为展示色阈值，不触发切换。
- 重置密码仅单台，弹窗展示目标信息并点击按钮确认，无需手动输入 VEID（按用户后续要求简化）；页面自动携带 VEID 供后端核对。持久记录请求状态、五分钟冷却、互斥；网络/异常响应视为结果未知，不自动重试。新密码只在此次响应和临时弹窗显示，不存库、日志或浏览器存储，响应 no-store。
- 本轮为本地开发，不部署生产或操作截图中的真实凭据。

验收：内存 SQLite 与 fake HTTP 验证 CSV、加密隐藏、供应商错误/限流、独立队列、IP 匹配和密码操作边界；桌面/移动浏览器验证真实后台壳、导入、筛选、备注、刷新、移除和密码确认；运行自动化及后台资源版本回归。
