# 公共检测账号按权限组配置

按权限组各保存一个检测账号，支持 level2、level3 同时配置。固定配置逐行显示权限组、已选账号与搜索/保存/清除操作；搜索只返回该权限组用户。

节点检测按节点 group_ids 的数字升序选择已配置且有效、具有该节点实际使用权限的账号。多组节点允许跳过无效候选；全部候选不可用时报告配置错误，不累计节点故障。不改变用户、套餐或节点的权限。

新增 settings JSON 映射，旧全局账号只迁入其实际所属权限组，清除全局字段，禁止回退。升级前须暂停全部策略并等待操作完成；迁移和账号变化均清除旧检测与备用认证，保留 DNS 绑定和待检查 VPS。保存保持现有公共锁与各域名锁，服务端校验用户归属、有效期和流量。

验证覆盖两组不同节点、同域名混合权限、账号归属不符、多组节点选择、过期/封禁/改组/流量耗尽、保存与清除、迁移及锁保护。仅修改当前分支文件，不发布生产。
