# 节点状态列表均衡列宽设计

## 目标

解决节点状态页右侧“状态、倍率、标签”三列过窄，导致表头与状态文字逐字换行的问题，同时保持国家/地区、名称、状态、倍率和标签的现有顺序与业务行为。

## 已选方案

采用 A「均衡留白」：国家/地区和名称继续使用弹性宽度；状态与倍率分别保留约 88px 的安全宽度；标签保留至少 140px；列间使用稳定间距。状态、倍率和标签的表头及单元格内容均禁止换行。

名称列占据剩余空间，长名称沿用现有溢出策略。桌面宽度下不出现文字竖排；窄屏下优先保留可读性，允许列表采用受控横向空间，而不是压缩右侧文字。

## 范围

- 仅修改节点状态列表的列宽类与不换行约束。
- 不修改节点数据接口、国家/地区识别、在线状态判断、状态颜色、倍率值或标签内容。
- 同步 `theme/ElephantRoute` 与 `public/theme/ElephantRoute` 的前端资源，并更新缓存版本。

## 验证

- 更新聚焦回归测试，约束右侧列的安全宽度与不换行规则。
- 运行 Dashboard 2.0 聚焦测试与全量 Node 测试。
- 检查主题与 public 资源字节一致、`git diff --check` 通过。
- 在本地 `#/node` 页面做干净刷新，确认桌面视口下表头和“在线/离线”均为单行，右侧留白均衡，控制台无新增错误。
