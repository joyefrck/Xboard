# 工单附件界面一致性设计

## 目标

- 后台工单消息中的附件链接采用与 ElephantRoute 用户端一致的 14px 蓝色下划线样式。
- 用户端工单详情的回复框、回复按钮和附件选择区始终完整显示，不被详情卡片裁剪。

## 设计

后台仅调整附件链接自身的字号、颜色、下划线和下划线偏移，保留后台消息气泡、左右对齐和间距结构。

用户端详情卡片改为纵向 Flex 布局：消息区使用 `flex-1 min-h-0` 占据剩余空间并独立滚动；回复输入与附件选择器放入 `shrink-0` 的底部组合区。附件从 0 张增加到 3 张时，底部组合区自然增高，消息区同步缩小，不再依赖固定的 70px 高度。

## 交付与验证

- 修改主题源资源并同步 `public/theme/ElephantRoute`、gzip、Brotli 与 Blade 缓存版本。
- 修改后台编译资源，不改变附件打开、上传或鉴权行为。
- 增加静态回归断言，并在真实浏览器中检查桌面和移动尺寸下的边界、可见性及控制台错误。
