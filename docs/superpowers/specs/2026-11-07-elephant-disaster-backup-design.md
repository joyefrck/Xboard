# 大象网络异地防灾备份设计

用户最终批准：香港阿里云 → 硅谷搬瓦工 67.216.201.209；每天北京时间 03:10 一次完整加密备份，保留最近 7 个成功日版本，无小时、周、月版本。2026-11-07 实测目标可用 144 GiB，源 Xboard 数据库约 449 MiB，应用目录约 2.3 GiB。

## 实施架构

为匹配简化后的短期保留，使用独立的每日完整归档，通过 OpenSSL CMS 公钥加密后经受限 SSH 上传。目标主机只有密文；解密私钥在用户 Mac 上独立保存。源机也不持有解密私钥。取消 Borg 仓库及 binlog 方案，不重启数据库。

目标使用新建的 100 GiB 稀疏文件系统，root 控制挂载和受限命令；专用非 sudo 账号只能上传当天备份和读取脱敏状态，不能 shell/SFTP/转发/删除。Mac 维护密钥单独允许列出、下载密文。挂载缺失时拒绝写入，避免落入根盘。80 GiB 预警。

每天生成数据库一致性 SQL、Redis 有效导出、APP_KEY/环境、附件/代码、系统/1Panel/代理配置、容器及镜像恢复清单。按盘点纳入业务服务；未发现或未检查的外部支付、节点、签名材料必须标明未覆盖。尽量保存正在运行的镜像，避免恢复依赖可变标签。

上传使用声明大小、SHA-256、临时文件及原子提交；只接受当天一次成功上传。目标独立 root 维护任务在完整校验成功后保留最新 7 个成功日版本；上传失败不淘汰旧版本。无周/月归档。传输限速、低 CPU/I/O 优先级，任务互斥。

## 验收和边界

从硅谷实际取回密文，在 Mac 用离线私钥解密并核验归档和关键文件哈希；隔离数据库恢复验证、附件对应和加密凭据解密测试。记录下载站/生产全部队列基线与三次后续样本及新连接复查。定时任务每日一次，RPO 约 24 小时加任务耗时，不提供 PITR。服务器 root 仍可删除备份，不宣称 WORM。

Gokapi 自身需要异地副本，排除备份盘与已有历史备份以防递归。未实际完成的副本或恢复项目必须在交付中标明。
