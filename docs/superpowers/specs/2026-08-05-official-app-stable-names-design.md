# 官方应用固定名称设计

## 目标

官方安装包的应用主记录不再使用文件名、平台版本号或管理员临时输入作为名称。名称固定为：

- Android：`大象网络官方App安卓版`
- Windows/macOS：`大象网络官方App桌面版`

版本号继续只保存在版本记录的 `version` 字段中。第三方应用名称保持可编辑。

## 设计

`DistributionApp` 作为官方身份策略的唯一后端来源，同时提供平台到官方标识、平台到官方名称的映射。`AppPackageController::saveApp()` 在保存官方应用时同时覆盖 `app_key` 与 `name`，防止绕过前端提交错误名称。

管理页面提供相同的平台名称映射。选择官方应用后，名称和标识都自动填充并锁定；切换 Android、Windows 或 macOS 时同步更新。第三方类型解除锁定，维持现有自动识别和手工编辑流程。

新增数据迁移，将已有的 `elephant-route-android` 和 `elephant-route-desktop` 官方记录纠正为固定名称。迁移不修改版本号、安装包、平台或下载记录；`down()` 不猜测并恢复不可知的旧名称。

## 验收

- 官方 Android 发布请求保存为 `大象网络官方App安卓版`。
- 官方 Windows/macOS 发布请求保存为 `大象网络官方App桌面版`。
- 前端官方名称字段只读，第三方名称仍可编辑。
- 现有官方主记录能通过迁移归一化。
- 官方更新仍按现有 `app_key`、`platform`、`channel` 和架构选择版本。
