# 黑名单按封禁时间降序

用户已明确要求按封锁时间降序，并授权修改后直接发布生产。

后端以每个账号最近一次 `account_ban` 或 `ticket_mute` 事件的 `created_at` 降序排序，再分页；时间相同时按用户 ID 降序稳定排序。解除封禁事件不改变封锁时间；历史封禁没有处罚时间时排在有记录的账号之后，不用账号更新时间推测封禁时间。保留现有搜索、状态筛选、最近处理原因和证据查询。

前端当前页排序无法覆盖分页；按账号更新时间排序会被其他用户编辑影响，均不采用。无需修改数据库或前端资源。

验证覆盖永久封禁与禁言交错、跨页顺序、解除事件不置顶、历史无时间记录，以及时间相同的稳定顺序。
