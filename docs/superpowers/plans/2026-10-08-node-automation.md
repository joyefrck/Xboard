# 节点自动化配置 Implementation Plan

**Goal:** 按已批准方案提供按域名组织的备用池、真实代理检测与 Cloudflare DNS 故障切换。

**Architecture:** 独立配置和持久化切换日志；每分钟调度独立队列；同一域名的配置、检测和 DNS 写入共用锁。先持久化 DNS 操作意图，再写 DNS，丢失响应或任务中断时回读恢复。

**Tech Stack:** Laravel 12、Eloquent、Redis/Horizon、sing-box 1.14.2、现有 React 后台。

- [x] 数据与 API：新增连接、域名策略、备用、检测结果和日志表；Token encrypted/hidden；管理接口继承 admin/log 中间件。
- [x] Cloudflare：限定 zone；唯一 A、无 AAAA/CNAME、DNS only；回读确认写入与外部修改保护。
- [x] 探针：复用 SingBox 协议构建方法；有效现有用户；固定 IP 和原 SNI；回环 SOCKS；双 204 地址；8 秒超时和独立进程清理。
- [x] 状态机：3 次失败、备用全部节点两次通过、当前恢复取消、10 分钟冷却、旧 VPS 待检查、持久化恢复及传播状态。

## 公共检测账号调整（用户已确认）

所有域名和节点只配置一个公共检测账号。账号独立于 Cloudflare 连接保存；真实代理检测始终读取公共账号，仍按节点校验权限、有效期和流量。移除域名内的逐节点账号选择。

- [x] 新增全局设置及升级迁移：旧配置全部使用同一用户时自动迁入，否则留空；升级暂停旧策略并要求重新验证。
- [x] 新增公共账号保存 API：按连接及所有域名加锁，启用策略或存在操作意图时拒绝修改；修改后清除旧检测与备用认证结果。
- [x] 域名配置 API 只接收域名；探针统一读取公共账号；页面顶部一个账号入口，域名区只显示共用说明与 DNS 匹配。
- [x] 隔离数据库验证账号共用、账号权限不足、变更失效和并发保护；浏览器验收单一入口与手机布局。
