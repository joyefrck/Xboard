# 管理后台收入概览统计周期实施计划

**目标：** 收入概览支持天、月、年；默认按天，切换时同步范围、请求参数、图表刻度和自定义范围输入。

**实现：** 沿用 `v2_stat` 日报数据，在 `StatController::getOrder` 按自然月/自然年汇总；金额和数量求和后重新计算平均值。默认请求保持按天兼容。管理端仅有编译资源，在现有收入组件内修改，保留其他仪表盘功能。

- [x] 接口增加 `period=day|month|year`，规范化月/年边界，验证日期顺序，返回升序周期统计和汇总。
- [x] 前端增加周期选择：天保留现有预设；月提供最近 3/6/12/24 个月；年提供最近 3/5/10 年。月默认 12 个月、年默认 5 年，均包含当前周期。
- [x] 自定义按天使用现有日历，按月使用月份输入，按年使用年份下拉；开始晚于结束时联动另一个边界。切换周期重置到对应默认范围。
- [x] 同步中文、英文、韩文文案及缓存版本。
- [x] 使用 SQLite 的真实接口测试覆盖跨年、闰月、范围边界、笔数、平均值、空数据及类型过滤；执行前端周期逻辑与交互测试、语法检查和现有回归测试。

用户已追加授权：验证完成后在当前 master 分支提交、推送并发布生产。采用已有 1Panel Docker 部署方式，只重建 Web，检查 Horizon、Redis 和线上页面。
