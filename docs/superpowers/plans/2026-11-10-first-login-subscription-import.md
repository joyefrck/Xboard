# 首次登录订阅导入修复

**目标：** 首次登录后点击一键导入时，不显示缺少订阅地址的残缺菜单。

**原因与范围：** Dashboard V2 与底层 Vue 页面分别读取订阅。已用真实浏览器和模拟 API 验证：底层初始化请求失败、V2 请求成功时，可点击的导入入口只展示二维码行。修复 ElephantRoute 底层菜单的打开入口，不改变菜单布局、客户端链接格式或 API。

**实现：** 已有订阅地址时立即打开；缺失时等待 `getUserSubscribe()` 重新获取并验证地址；重复点击共用进行中的加载；请求失败或无地址时提示错误并允许下次重试。同步 theme/public 文件、压缩包和 Blade 缓存版本。
