# 工单客服退款与本期调档实施计划

1. 在工单路由增加按操作授权的服务凭据。沿用现有工单版本和幂等回执，已成功请求先返回原回执，再判断版本或预览有效期。
2. 退款入口在事务中按工单归属锁定用户和订单。复用 OrderRefundService 的报价、佣金、回收和通知，另存工单来源及真实服务身份。
3. 在用户记录保存本期目标套餐和截止时间。节点权限同步仅在消费订阅流量时采用目标档位。换购、退款、恢复和到期时撤销，续费保留原截止时间。
4. 用 HTTP 测试覆盖权限隔离、跨用户和跨工单、重复确认、流量包、续费和到期。用原有退款及节点权限测试核对兼容性，将新增配置与调用方式写入工单接口指南。
