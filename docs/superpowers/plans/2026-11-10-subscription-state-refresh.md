# 账户刷新导致订阅菜单消失的修复

根因：钱包组件在 mounted 和 window focus 时调用用户 store 的 getUserInfo；该方法整体替换 userInfo，而账户响应没有 subscribe 或 plan。先返回的订阅或已打开菜单所依赖的状态因此被清空。上一轮打开前检查未覆盖后续刷新。

修复：同一账户合并账户响应并保留独立加载的订阅及套餐字段；账户 UUID 变化时整体替换，避免沿用旧账户订阅。保留打开前加载和失败重试。只修改 ElephantRoute bundle 及缓存版本，不修改钱包刷新行为。
