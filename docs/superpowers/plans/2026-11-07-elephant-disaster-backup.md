# 大象网络每日七版备份 Implementation Plan

**Goal:** 每天北京时间 03:10 备份一次，只保留 7 个成功日版本。

**Architecture:** 一致性数据库及文件/配置/镜像归档，CMS 公钥加密，受限 SSH 上传到硅谷 100 GiB 文件系统；源端不能删除，目标端独立轮转，Mac 独立密钥恢复。

**Tech Stack:** Python 3、OpenSSL、OpenSSH、Docker、MariaDB、systemd。
