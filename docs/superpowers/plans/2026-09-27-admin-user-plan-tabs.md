# 用户管理套餐类型 Tab

按用户给出的套餐管理样式，复用现有 Tabs。用户管理默认「全部用户」，另有「普通套餐」「私人定制」「用户专属」。按当前绑定套餐的 plan_type 分类；历史空类型按普通套餐处理，无套餐和失效关联仅保留在全部用户。套餐到期不改变分类；定制开通后随绑定套餐进入用户专属。

- [x] 在 UserController 共用过滤入口添加独立 plan_type 参数，严格校验四种取值，分页前执行关系查询；导出、邮件、批量操作共享相同查询条件。
- [x] Hp 保存独立 Tab 状态，列表请求与缓存键带套餐类型，切换重置页码与选择，保留邮箱、排序、高级条件。Kp 复用 Tabs，table meta 向现有操作传递类型，重置高级筛选不重置 Tab。
- [x] 用 SQLite 内存数据库验证分类、无套餐、已过期用户、条件交集、分页、非法类型；用前端组件测试验证 Tab 和请求联动。
- [x] 更新资源版本，运行相关测试、PHP/JS 语法与差异检查。
