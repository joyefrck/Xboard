# 到期后新购退款及订单弹窗修复

目标：到期后新购只按当前订阅计算退款与佣金校验；订单详情及退款弹窗完整限制在视口内。

生产只读证据：订单 27808 是新的 type=1 月付，佣金状态 3、实发为空、无流水；现有折抵错误纳入历史订单 22584（已结算佣金），导致退款预览失败。既有期限折抵查询只按完成状态筛选，未切断已结束的新购周期。详情及退款弹窗使用 `max-h-[90dvh]`，但已编译 CSS 只有 `max-h-[90vh]`，高度限制未生效。

方案：统一期限订阅查询，限定当前套餐，按最近完成的新购/升级订单切断历史周期；保留同周期续费、既有折算公式及佣金保护。换套餐、同套餐续费、退款共用范围，避免修复后计算分歧。未找到新购起点的历史续费保持原有兼容行为。独立流量包与旧不限时分支保持既有处理。

弹窗沿用现有布局，改用已编译的 `max-h-[90vh]` 与内部滚动，不新增视觉样式或依赖。
