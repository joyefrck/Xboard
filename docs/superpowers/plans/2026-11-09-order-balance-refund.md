# Prorated Order Balance Refund Implementation Plan

**Goal:** 复用换套餐折抵计算，退款同时回收对应权益。

**Architecture:** OrderService 暴露原有剩余价值计算的只读入口和指定折算时间；OrderRefundService 负责范围识别、签名报价、锁内重新核对和原子回收；订单关联表映射合并退款记录。

**Tech Stack:** Laravel/Eloquent、Crypt、React/Radix、SQLite/MySQL fixtures、Playwright CLI。

- [x] 暴露共享换套餐折抵方法，原有购买路径及默认时钟行为保持兼容。
- [x] 新增审计快照与关联表 migration/model/relation。
- [x] 实现订阅整体及独立流量包两类折算范围、签名预览及事务回收，所有关联订单校验佣金并关闭。
- [x] 更新管理员退款参数与前端金额、范围、回收说明和重新核对；去除原“保留权益”文案。
- [x] 重写隔离集成测试，以已有换套餐计算为金额 oracle；覆盖报价、回收、关联审计、回滚和并发。
- [x] 更新浏览器 fixture 并验收；运行相关回归、语法、内容版本和差异检查。
