# macOS 1.6.4 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an arm64 macOS `1.6.4+10604` DMG with the established external and internal application names.

**Architecture:** Keep the cross-platform version untouched and make the macOS packaging script accept explicit platform version inputs. Enforce the version and naming contract in a source-level Flutter test, then validate the mounted DMG offline.

**Tech Stack:** Bash, Flutter macOS, XCTest build tooling, `flutter_test`, `hdiutil`, `codesign`, `lipo`

and continue staging `大象网络.app`.

- [x] **Step 2: Run the contract test and verify it fails**

```bash

```

Expected: failure because the script does not yet contain the version inputs or
versioned filename.

- [x] **Step 3: Implement explicit macOS version inputs**

Add semantic version/build-number validation, append these arguments to
`BUILD_ARGS`, and derive the DMG path from the requested macOS version:

```bash
MACOS_BUILD_NAME="${MACOS_BUILD_NAME:?MACOS_BUILD_NAME is required}"
MACOS_BUILD_NUMBER="${MACOS_BUILD_NUMBER:?MACOS_BUILD_NUMBER is required}"
DMG_PATH="${EXPORT_DIR}/${APP_NAME}-macos-${MACOS_ARCH}-v${MACOS_BUILD_NAME}.dmg"
BUILD_ARGS+=(
  --build-name="${MACOS_BUILD_NAME}"
  --build-number="${MACOS_BUILD_NUMBER}"
)
```

Update the release documentation with the `1.6.4+10604` command and output.

- [x] **Step 4: Run source-level verification**

```bash
bash -n build_macos_beta.sh
flutter test test/macos_distribution_contract_test.dart
git diff --check
```

Expected: shell syntax is valid, all contract tests pass, and the diff check is
silent.
