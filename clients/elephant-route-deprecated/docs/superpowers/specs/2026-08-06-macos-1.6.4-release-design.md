# macOS 1.6.4 Release Design

## Goal

Package the macOS latency reliability repair as the platform-specific
`1.6.4+10604` arm64 release without changing the Windows/Android version stored
in `pubspec.yaml`.

## Release Contract

- The build command receives explicit macOS `--build-name=1.6.4` and
  `--build-number=10604` values.
- The final artifact keeps the established external name
  `ElephantRoute-macos-arm64-v1.6.4.dmg`.
- The application inside the DMG keeps the established Chinese name
  `大象网络.app` and the DMG volume name remains `大象网络`.
- The package remains arm64-only, ad-hoc signed, and not notarized.
- `pubspec.yaml` remains `1.6.7+10607` so the macOS release sequence does not
  overwrite another platform's version.

## Implementation

`build_macos_beta.sh` will require `MACOS_BUILD_NAME` and
`MACOS_BUILD_NUMBER`, validate them, forward them to `flutter build macos`, and
include the version in the DMG filename. The distribution contract test will
lock those requirements, while `docs/macos-beta-release.md` will document the
exact invocation and output pattern.

## Verification

Run the contract test and shell syntax check, build with
`MACOS_BUILD_NAME=1.6.4 MACOS_BUILD_NUMBER=10604`, mount the resulting DMG, and
verify the contained app version/build, app name, arm64 Mach-O slices, deep
signature, helper identifier, and SHA-256. The currently installed application
is not replaced during packaging verification.
